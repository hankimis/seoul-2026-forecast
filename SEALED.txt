PRE-REGISTRATION RECORD (git-timestamped, no cryptographic seal)

The 2026 forecast is pre-registered by its public git commit history, made
before polls closed. The committed forecast files are the fixed, timestamped
prediction of record:

  forecast-national.json   committed 2026-05-30 00:57 KST  (commit 370a40d)
  forecast-meta.json       committed 2026-05-30 00:57 KST  (commit 370a40d)
  data/results-2026-actual.json  placeholder committed 2026-05-30

Git history is the timestamp; these commits fix the numbers in advance. No file
is altered after the fact, so the forecast can be scored honestly against the
realized result.

Scoring (after results): fill data/results-2026-actual.json, then run
  node score.mjs
which grades vote-share MAE, two-way error, winner accuracy, Brier, and the
±3% hit rate against forecast-national.json.

Note: an earlier experimental cryptographic file-hash seal of the Seoul
LLM-persona prediction.json is retired and not used. That persona run is the
kept negative result, not the headline poll+fundamentals forecast, and its file
is git-ignored. The pre-registration above does not depend on it.
